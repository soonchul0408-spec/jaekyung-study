# 회차 추가 품질검사표

새 기출 회차를 추가할 때는 이 표의 모든 항목을 통과하기 전까지 배포하지 않는다. 기준 회차는 2025년 1월이며, 새 회차는 기존 화면·학습 기능과 같은 수준을 유지한다.

| 구분 | 필수 기준 | 자동 검사 |
|---|---|---|
| 원문·정답 | 공식 문제지와 확정답안만 사용하고, 과목별 40문항·총 120문항·4지선다를 충족한다. | `check:exam-parity` |
| 문제 근거 | 지문 근거와 ①~④ 보기별 실제 표현이 모두 존재한다. | `check:exam-parity` |
| 풀이 방향 | 지문 또는 보기의 핵심 표현, 구체적 판단 기준, 적용 순서를 모두 제시한다. | `check:exam-quality` |
| 정답·해설 | 정답 선택지의 실제 표현을 인용하고, 해설·판단 순서·보기별 분석·실수 포인트를 제공한다. | `check:exam-quality` |
| ‘옳지 않은 것’ | 정답을 `틀림(정답)`으로 표시하고, 틀린 문구와 올바른 기준을 연결해 설명한다. | `check:exam-quality` |
| 계산형 | 모든 계산형에 계산식, 수치 대입, 결과, 확정답안 대조를 넣는다. | `check:exam-quality` |
| 빈출 분석 | 실제 존재 문항만 TOP 12에 연결하고, ID 중복·존재하지 않는 ID·과목 불일치를 허용하지 않는다. | `check:frequency` |
| 화면 동등성 | 월 선택, 항목별 통합 복습, 문제 도구, 배지, 모바일 반응형을 기존 회차와 동일하게 유지한다. | `check:exam-parity` + 화면 확인 |
| 배포 | 모든 검사와 프로덕션 빌드가 성공해야 한다. | 아래 명령 전체 |

## 배포 전 필수 명령

```bash
npm run check:frequency
npm run check:exam-parity
npm run check:exam-quality
npm run check:explanations
npm run build
```

## 현재 기준 회차 결과

| 회차 | 계산형 상세 계산 | ‘옳지 않은 것’ 오답 이유 | 풀이 방향 | 상태 |
|---|---:|---:|---:|---|
| 2025년 1월 | 39/39 | 49/49 | 120/120 | 통과 |
| 2025년 3월 | 41/41 | 49/49 | 120/120 | 통과 |

검사 통과는 데이터·구조·지문 연결 기준을 자동으로 확인한 결과다. 계산·규정의 사실관계가 원문 또는 확정답안과 충돌하면 해당 문항은 `reviewNeeded: true`로 되돌리고 수정 후 다시 검사한다.
