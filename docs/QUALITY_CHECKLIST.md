# 회차 추가 품질검사표

새 기출 회차를 추가할 때는 이 표의 모든 항목을 통과하기 전까지 배포하지 않는다. 기준 회차는 2025년 1월이며, 새 회차는 기존 화면·학습 기능과 같은 수준을 유지한다.

| 구분 | 필수 기준 | 자동 검사 |
|---|---|---|
| 원문·정답 | 공식 문제지와 확정답안만 사용하고, 과목별 40문항·총 120문항·4지선다를 충족한다. | `check:exam-parity` |
| 문제 근거 | 지문 근거와 ①~④ 보기별 실제 표현이 모두 존재한다. | `check:exam-parity` |
| 풀이 방향 | 지문 또는 보기의 핵심 표현, 구체적 판단 기준, 적용 순서를 모두 제시한다. | `check:exam-quality` |
| 전문가 감수 완료 | 원문 독립 풀이, 정답 번호·선택지·해설의 대응, 계산 재검산, 문항 단독 학습 가능 여부를 전수 감수한다. | 전수 감수 기록 |
| 1월 모범사례 적용 | 이후 회차도 정답 원문 → 기준·예외 → 지문 적용 → 실수 포인트와 지문 조건 중심 판단순서를 같은 정답 선택지에 연결한다. | 생성기 확인 + 전수 감수 |
| 선택지-해설 대응 | 정답 번호와 선택지 원문, 해설의 인용·논점·결론이 같은 선택지를 가리킨다. 다른 문항·다른 선택지의 설명 재사용은 불가하다. | 전수 감수 |
| 계산 재검산 | 모든 등식·중간값·단위·부호·포함·제외와 최종 선택지를 독립 확인한다. 충돌 시 `sourceVerificationNote`와 검토 상태가 필수다. | 전수 감수 + `check:explanations` |
| 정답 해설 중심 | 말문제는 정답 선택지의 실제 표현·기준·예외·정답 논리만 필수로 검토한다. 오답별 공통 템플릿 해설을 만들지 않는다. 계산형은 상세 산식·중간값·정답 대조를 유지한다. | 전수 검토 |
| 정답·해설 | 정답 선택지의 실제 표현을 인용하고, 해설·판단 순서·보기별 분석·실수 포인트를 제공한다. | `check:exam-quality` |
| ‘옳지 않은 것’ | 정답을 `틀림(정답)`으로 표시하고, **틀린 문구 → 정확한 올바른 기준 → 이 선택지가 정답인 이유**를 설명한다. “단원 기준과 맞는지 확인” 같은 빈 문구는 불가하다. | `check:exam-quality` + 전수 검토 |
| 수험생 해설성 | ①~④ 모두 실제 표현과 기준을 근거로 설명하며, 공통 템플릿만 반복하지 않는다. | 자동 탐지 + 전수 검토 |
| 풀이 방향 실전성 | 해당 지문의 판단 순서·예외·수치·기간을 제시한다. | 자동 탐지 + 표본 검토 |
| 사실·논리 정확성 | 해설의 기준·수치·부등호·기간·분류가 원문·정답과 일치하고 내부 모순이 없다. | 전수 검토 |
| 계산형 적합성 | 실제 계산 필요 문항에만 계산형을 적용하고, 산식·중간값·정답 대조를 제공한다. | 자동 검사 + 전수 검토 |
| 계산형 | 모든 계산형에 계산식, 2단계 이상 수치 대입, 결과, 확정답안 대조와 ‘무엇을 구하는지→중간값→최종값→실수 방지’ 수험생용 설명을 넣는다. | `check:exam-quality` + `check:explanations` |
| 빈출 분석 | 실제 존재 문항만 TOP 12에 연결하고, ID 중복·존재하지 않는 ID·과목 불일치를 허용하지 않는다. | `check:frequency` |
| 화면 동등성 | 월 선택, 항목별 통합 복습, 문제 도구, 배지, 모바일 반응형을 기존 회차와 동일하게 유지한다. | `check:exam-parity` + 화면 확인 |
| 배포 | 모든 검사와 프로덕션 빌드가 성공해야 한다. | 아래 명령 전체 |

## 배포 전 필수 명령

```bash
npm run check:frequency
npm run check:exam-parity
npm run check:exam-quality
npm run check:explanations
npm run audit:student-explanations
npm run build
```

## 현재 기준 회차 결과

| 회차 | 계산형 상세 계산 | ‘옳지 않은 것’ 오답 이유 | 풀이 방향 | 상태 |
|---|---:|---:|---:|---|
| 2025년 1월 | 형식 통과 | 정답 선택지 보완 완료 | 공통 선택지 해설 보완 필요 | 보완 필요 |
| 2025년 3월 | 형식 통과 | 정답 선택지 보완 완료 | 공통 선택지 해설 보완 필요 | 보완 필요 |
| 2025년 5월 | 형식 통과 | 정답 선택지 보완 완료 | 공통 선택지 해설 보완 필요 | 보완 필요 |

검사 통과는 데이터·구조·지문 연결 기준을 자동으로 확인한 결과다. 계산·규정의 사실관계가 원문 또는 확정답안과 충돌하면 해당 문항은 `reviewNeeded: true`로 되돌리고 수정 후 다시 검사한다.
